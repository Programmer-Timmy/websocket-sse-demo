About This Project

This demo showcases the difference between WebSockets and Server-Sent Events (SSE), two powerful technologies for real-time communication between client and server.

The project consists of a Node.js backend with Express and a React + TypeScript frontend, styled with Tailwind CSS.

🚀 Live Demo Available: Click "Try Live Demo" above to see WebSocket and SSE in action! The demo connects to a production server at ws.school.timmygamer.nl.

Installation & Usage

Prerequisites

  • Node.js (v18 or higher)
  • npm or yarn

Steps

1. Clone the repository

git clone https://github.com/Programmer-Timmy/websocket-sse-demo.git
cd websocket-sse-demo

2. Install dependencies

npm install

3. Start the backend server (Terminal 1)

npm run server

Server runs on http://localhost:3100

4. Start the frontend (Terminal 2)

npm run dev

Frontend runs on http://localhost:5173

WebSocket vs Server-Sent Events

Feature WebSocket Server-Sent Events
Communication Direction Bi-directional (↔️) One-way (server → client)
Protocol WebSocket protocol (ws:// / wss://) HTTP/HTTPS
Use Cases Chat apps, multiplayer games, real-time collaboration Live feeds, notifications, dashboards, status updates
Browser Support Excellent (all modern browsers) Excellent (all modern browsers)
Reconnection Manual implementation Automatic built-in
Complexity Moderate Simple
Data Format Text, Binary (flexible) Text only (usually JSON)

🔌 WebSocket Features

  • ✓ Bi-directional real-time communication
  • ✓ Send messages from client to server
  • ✓ Receive instant responses
  • ✓ Broadcast to all connected clients
  • ✓ Connection status indicator

📡 SSE Features

  • ✓ One-way server-to-client streaming
  • ✓ Automatic updates every 2 seconds
  • ✓ Manual connect/disconnect controls
  • ✓ Real-time timestamps and data
  • ✓ Connection status indicator
